# SEO Audit — SparkCraft

Last reviewed: August 2026

> **Status update — 2 September 2026.** The audit below is retained as a historical
> record and describes the state of the site in August 2026. Most of its findings have
> since been resolved, and the company has been renamed from *Sparkcraft Consulting* to
> **Sparkcraft Technologies**. Read the "Current state" section immediately below for the
> live picture; treat the rest of this document as history.

---

## Current state (2 September 2026)

### Page metadata

All page metadata is produced by `createPageMetadata()` in `src/lib/seo.ts`, which sets
title, description, absolute canonical URL, robots, OpenGraph and Twitter tags from a
single input.

| Route | Title | Canonical | OG image |
|-------|-------|-----------|----------|
| `/` | Sparkcraft Technologies \| Intelligence & Infrastructure for African Markets | `https://sparkcraft.co.tz` | `/opengraph-image` |
| `/finspark` | FinSpark \| Last-Mile Financial Infrastructure | `https://sparkcraft.co.tz/finspark` | `/finspark/opengraph-image` |
| `/sparkgreen` | Sparkgreen by Sparkcraft \| Creative Carbon Solutions for Tanzania | `https://sparkcraft.co.tz/sparkgreen` | `/sparkgreen/opengraph-image` |

### Resolved since the August audit

| Element | Implementation |
|---------|----------------|
| `metadataBase` | `src/app/layout.tsx` — `new URL(SITE_URL)` |
| Domain | `SITE_URL` is `https://sparkcraft.co.tz`; `sparkcraftconsulting.com` no longer appears anywhere in `src/` |
| Canonical URLs | `alternates.canonical`, absolute, per route |
| OpenGraph images | Three dynamic 1200x630 `opengraph-image.tsx` routes (edge runtime) |
| Twitter cards | `summary_large_image` with image, per route |
| Favicon / app icon | `src/app/icon.svg`, `src/app/apple-icon.svg` |
| `robots.txt` | Generated by `src/app/robots.ts`, references the sitemap |
| `sitemap.xml` | Generated by `src/app/sitemap.ts` — `/`, `/finspark`, `/sparkgreen` |
| JSON-LD | `Organization` schema in `src/components/JsonLd.tsx` with `Brand` entries for FinSpark and Sparkgreen; `WebPage` + `Brand` schema on `/finspark` |

### Still open

- **HTTPS at the domain level.** DNS still points to Hostinger with an expired certificate,
  which continues to block crawling. See `docs/PROJECT-STATUS.md` and `docs/DOMAIN-DNS-SSL.md`.
- **Legacy root HTML.** `index.html` and `sparkgreen.html` remain in the repository and still
  carry the old company name. They are not served by Next.js, but they are a duplicate-content
  risk if the domain is ever pointed at static hosting.
- **No `hreflang`.** Single-language site; not required.

### Structured-data policy for `/finspark`

Only facts evidenced on the page itself are expressed in structured data. No ratings,
aggregate reviews, customer counts, launch dates, awards, licences or geographic coverage
claims are asserted, because none of them can currently be supported.

## Recommendations

### Immediate (fix with DNS/SSL resolution)

1. Point DNS to Vercel to restore HTTPS
2. Verify site is crawlable after DNS fix

### Short-term (code changes)

1. Set `metadataBase: new URL('https://sparkcraft.co.tz')` in root layout
2. Update OpenGraph URLs from `sparkcraftconsulting.com` to `sparkcraft.co.tz`
3. Add `app/sitemap.ts` for automatic sitemap generation
4. Add `public/robots.txt` with sitemap reference
5. Add favicon and app icons to `public/`
6. Add OG image (1200×630 branded image)

### Medium-term

1. Add JSON-LD Organization schema to layout
2. Add Twitter card metadata
3. Add canonical URLs per page
4. Remove or block legacy HTML from indexing (if still served)
5. Submit sitemap to Google Search Console (verification TXT record already present)

### Example: metadataBase fix

```typescript
export const metadata: Metadata = {
  metadataBase: new URL('https://sparkcraft.co.tz'),
  // ... rest of metadata with relative OG URLs
};
```

### Example: sitemap.ts

```typescript
import { MetadataRoute } from 'next';

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    { url: 'https://sparkcraft.co.tz', lastModified: new Date(), priority: 1 },
    { url: 'https://sparkcraft.co.tz/sparkgreen', lastModified: new Date(), priority: 0.8 },
  ];
}
```
